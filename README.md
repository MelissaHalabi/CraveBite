
# CraveBite 🍔

## Project Description

CraveBite is a food delivery website developed using ReactJS
for the CSCI426 Advanced Web Programming course.

The website allows users to explore restaurants, search for
their favorite food, view restaurant menus, and add items
to their shopping cart.

The goal of this project is to create a simple, attractive,
and user-friendly food ordering experience.

## Features

- Home page with food search
- Restaurant listings with category filters
- Restaurant menus with food images and prices
- Add to Cart functionality
- Shopping cart with total price calculation
- About Us page
- Contact Us page with a contact form
- Responsive design for different screen sizes

## Technologies Used

- ReactJS
- JavaScript
- HTML and CSS
- React Router DOM
- Git and GitHub
- Vercel for deployment

## Project Pages

1. Home - Introduction and food search.
2. Restaurants - Browse and filter restaurants.
3. Menu - View food items and prices.
4. Cart - Manage selected food items.
5. About Us - Information about CraveBite.
6. Contact Us - Contact form and information.

## How to Run the Project

1. Download or clone the GitHub repository.
2. Open the cravebite-app folder in VS Code.
3. Open the terminal.
4. Install the dependencies:

   npm install

5. Start the React application:

   npm start

6. Open http://localhost:3000 in your browser.
